# MiSS 验证记录 — 2026-09-18

[English](VALIDATION.md) | 简体中文

环境：RTX PRO 6000 Blackwell Workstation Edition，CUDA 架构 sm_120，
NVIDIA 驱动 610.57.04，CMake Release 构建。
Python 参考实现使用本地 PyTorch 2.14.0+cu130。无可用 ROCm SDK 和 AMD 设备。

## 正确性

- CTest：15 项 GPU/主机测试通过。依赖测试数据的模型可执行文件在 CTest 无参数调用时跳过；显式传入生成的测试数据运行后，FP16 预填充/解码、并发和重载测试通过。
- `tools/check_miss.py`：覆盖显式固定 A 的 PyTorch/autograd 参考、CPU 有限差分、整除和不完整布局、dD 累积、两层完整 RWKV autograd、chunk=30 与 chunk=7 比较、batch-size=2 累积、共享 WKV 重放记录和冻结初始状态序列化。
- 完整模型适配器梯度的相对 L2 误差最大约 0.115%，验收阈值为 0.5%。损失/参考值为 5.2124 / 5.212386。
- 在重复 ASCII 测试样本上，16 次优化器更新后损失由 5.2124 降至 2.9414。
- 连续四次更新与两次更新后续训相比，FP32 D 主副本、动量及 FP16 推理导出逐位相同。
- 动态 FP16、W8A16 和 W4A16：覆盖预填充/解码、完整/分块预填充、不同内容版本及 scale 并发、零 scale 等价、不兼容状态拒绝、SQLite 身份往返和驱逐/重载。
- RAM、GPU 和暂存预算准入拒绝；八个并发同版本未命中只上传一次；活跃租约阻止驱逐；删除注册保留已有句柄；最新版本回退遵循注册顺序。
- HTTP 注册/列表/删除、冷/热生成、按 scale 隔离会话，以及按逻辑会话 ID 删除。注册后 uploads=0，首次生成后 uploads=1，重复生成仍为 1。

模型为小型合成模型（2 层，C=64，F=128，词表 256）。这验证计算链路和序列化，
不是预训练模型质量基准，也不是大模型训练稳定性结果。

本机还通过了正式二进制的冒烟测试：共享 WKV 记录的单步状态微调及检查点导出；
新生成 W8A16/W4A16 量化文件并分别执行 MiSS 推理；HTTP 适配器注册、冷/热生成、
列表与删除；未量化 7.2B 服务请求。7.2B 提示词 `The capital of France is` 生成了
连贯的贪心续写，并测试了服务状态和 token 计数端点。

## 算子测量

使用 `tools/bench_miss.cpp`，K=N=4096、rank=16，预热 10 次、计时 100 次，
以 CUDA 事件计时，不包含基模 Linear 或 H2D。解码前向使用融合实现，训练形状保存 S。
反向包含 dD 和适配器 dX 累积。基线与优化后的独立二进制均使用
`nvcc -O3 -std=c++17 -arch=sm_120`。

| 行数 | 初始前向 µs | 优化后前向 µs | 初始反向 µs | 优化后反向 µs |
|---:|---:|---:|---:|---:|
| 1 | 38.478 | 2.545 | 68.727 | 5.329 |
| 64 | 14.680 | 14.742 | 90.938 | 11.902 |
| 256 | 30.122 | 22.605 | 127.624 | 34.771 |
| 1024 | 61.403 | 50.715 | 817.094 | 126.511 |

初始算子为每个归约槽使用一个线程通道，每个 dD 元素使用一个 CTA。
优化版在 CTA 内分配归约工作，短分块每个 dD 元素使用一个线程，长分块共享 G/S 数据块。
这些时间来自一次本地微基准，受频率和桌面负载波动影响，不能证明端到端训练加速。

构建后使用 `./build/rwkv_miss_bench` 运行维护中的基准。

## 性能分析状态与待验收项

Nsight Systems 2026.3.2 生成了训练 CUDA 追踪。最初的小型训练追踪中，WKV 反向占算子
时间的 13.5%；MiSS 投影平均约 1.02 µs，dD 为 1.76 µs，dX 为 1.08 µs。
随后融合了小投影的归约与投影，因此这些初始时间不能代表最终融合实现。

[MiSS 文档](README.zh-CN.md) 中的 7.2B 训练命令在性能分析运行被主动停止前完成
26 次更新，持续吞吐约 2.14k token/s，显存约 22.0 GiB。
在 238 个稳定的一秒 Blackwell GPM 样本中，GPU 忙碌率均值 99.8%，SM 活跃度 52.0%，
占用率 12.9%，Tensor/HMMA 活跃度 15.4%，DRAM 活跃度 20.9%，平均功耗 401.6 W。
这表明，对于当前顺序微批次路径，普通 `nvidia-smi` GPU 利用率明显高于实际算术利用率。

Nsight Compute 2026.3 可以附加进程，但分析算子时报 `ERR_NVGPUCTRPERM`。
访问硬件计数器需要管理员配置，因此仍无法给出精确的实际 FLOPS 百分比。
测量前置条件、按形状优化 MiSS、真实微批次方案及验收目标见 [优化计划](OPTIMIZATION_PLAN.zh-CN.md)。

HIP 共享可移植 MiSS 算子源码并具备相应前向/反向钩子，但 HIP 编译以及 AMD 数值/性能
执行尚未验证。大规模预填充的 Tensor Core 投影/dD、并行训练微批次，以及大型预训练
模型吞吐调优也仍是后续性能工作。
